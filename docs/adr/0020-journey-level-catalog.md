# Journey catalog is 120 levels; spikes are guests

Launch Hero Journey is a **120**-level catalog (six Issues × 20 Chapters). Difficulty is a **toolkit** that unlocks slowly (Hero count, Affix families, decoy density, timers). Inside the current toolkit, levels **rollercoaster** across those axes so a hard level is a **guest**, not a new floor — later levels may drop that Affix and raise Hero count or wrong-sound count instead. Peak toolkit around level **85**; **86–120** remix at that peak (variety, not a third climb). Dire Heroes stay off the row until portraits ship.

**Why 120, not 50 / 80 / 150:** `journey level` only rises, so sequel rows are endgame for anyone who finished launch. 50–80 spends that one-way budget too soon. 150 is mostly remix after ~90 (126 Heroes, 16 Affixes) and goes stale unless the extra 30 are the same peak — better saved for Dire / new Affixes. Authoring: skill `journey-level-authoring`. Spine still ADR-0015 (no XP). Chapter capacity still ADR-0019 (do not author more playable levels than active Issue Chapters at publish).

**Rejected:** monotonic floor raises after each spike; shipping a short launch catalog and “adding easy levels later”; climbing difficulty through 150; Sudden Death only at the end (it is a heart **guest** after Fragile Spirit); using off-screen Dire as a hidden identity load before Dire portraits.
